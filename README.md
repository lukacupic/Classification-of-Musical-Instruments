# Classification-of-Musical-Instruments

Master's Thesis at FER, University of Zagreb, 2020. The central point of the thesis a mobile application that recognizes which musical instrument is playing in real-time. The recognition is based on the probability that the currently recorded instrument belongs to one of the known instrument classes.

The app uses a machine learning classification model written in Python, trained on real musical instrument data, and converted to TensorFlow Lite for local inference on mobile devices. The generated model (~2.3 MB in size) is used in the Android application to allow instrument classification in real-time.
